# F4.1 — Academic management architecture (one app, subject-centred)

## Layers

```text
UI (F15, PySide6)                      -> only AcademicApp (facade)
Application (no Qt, no SQL)
  career / evaluation / course material / calendar / knowledge /
  planning / unified search / backup / gestion migration
Domain + Ports (stdlib only)
  entities (Subject, Term, Task...), career, evaluation, grading,
  schedule, conflicts, course_material, planning, resources, identity
Infrastructure
  repositories + academic_store (SQLite), FileBlobStore (CAS), FTS5,
  ics adapter, legacy_gestion reader (read-only)
SQLite (one database: academic.db) + CAS + FTS
```

Facade attributes added in F4.1 (`application/facade.py`): `career`,
`evaluation`, `material`, `calendar`, `plans`, `knowledge`,
`unified_search`, `migration`, plus repositories `evaluations`,
`course_material`, `study_spaces`, `series`, `personal`.

## Subject-centred relations

```text
Degree ─< AcademicYear ─< Term(state actual|pendiente|superado)
                              └─< Subject (state -> AcademicStatus)
Subject ─< SubjectStaff >─ Professor           (role, order, per-link contact)
Subject ─< prerequisites >─ Subject
Subject ─< AssessmentScheme ─< AssessmentBlock ─< AssessmentComponent (MinGrade)
Subject ─< CourseDocument >─ Resource(CAS, versions, provenance, FTS, pages, AST)
Subject ─< DocumentGroup                        (per category)
Subject ─< ExternalResource                     (URL only, never fetched)
Subject ─< Task (subject optional) ─ StudySpace ─< StudySpaceDocument >─ Resource
                                              └< StudySpaceGoal
Subject ─< schedule_series (sessions expanded on demand; conflicts warn)
Subject ─< Milestone (optional) · StudyConcept (data only, F11)
Subject ─< Lab / Assignment / Exam / Project (F1/F8 records, ids in detail view)
```

## Home / Carrera contract (consumed by F15)

- `CareerService.home(today)` -> `HomeView`: current terms, CURSANDO subjects
  of those terms, their study spaces (+progress), upcoming/overdue tasks,
  this week's agenda (tasks + class sessions), continue-reading, due
  concepts count, milestones, degree progress (plan total is a setting),
  average summary. Home never lists the whole catalogue.
- `CareerService.career()` -> `CareerView`: partition (current, in progress
  elsewhere, approved, failed, not taken, not chosen), per-term means,
  target average.
- `CareerService.course(subject_id)` -> `CourseDetail`: information, status,
  professors, prerequisites, evaluation (+schemes), documents by category,
  groups, external resources, series, tasks, milestones, study spaces,
  concepts, labs/assignments/exams/projects ids.
